# Output language: English

<!-- devops-ai-kit · Installed as rules/devops-kit/01-language.md by `./install.sh --lang en`. -->

- Write all documents and reports in English: concept notes, runbooks, change records, postmortems, ADRs, agent reports, README, PR descriptions, commit messages and code comments.
- Use plain, clear English: short sentences, common words.
- In chat, reply in the language the user writes in.
- Keep headings, placeholders, field labels, file and folder names exactly as the templates write them. Agents find parts of other files by these names.
- The project's CLAUDE.md can override this rule.
